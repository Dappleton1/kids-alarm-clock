# Case

The printed parts live on MakerWorld alongside this project (link in the top-level README once posted).
Printed in ABS on a Bambu Lab; PETG is fine too. No supports on the base, the bezel prints face down.

Openings: 60 mm arcade button on top, 16x2 LCD and the TTP224 strip in the front bezel, a side slot
for the microSD so songs can be swapped without opening the case, USB-C power out the back.
